# Security

Use this edition only on localhost with fictional inputs. Never commit credentials, sessions, browser profiles, API diagnostics or client assets. Keep secrets in process environment or an ignored .env. Do not use production browser profiles with the demo.

Report suspected vulnerabilities privately to the repository owner through an established private channel. Never place secret values in public issues. If a credential may have been exposed, revoke and rotate it at the provider; deleting a file does not invalidate it. The local demo has no authentication and must not be exposed as a public service.
